# Case Study: Tourism

## The Challenge
Tourists hiking in a national park need to find their way to a specific hidden landmark.

## The Solution: Geo URI QRs
A QR code placed on a trail marker can contain a geographic URI (`geo:lat,lon`). Scanning it opens the user's maps application directly to the location.

### Core Library Example
See `examples/location_qr.rs` for generating Geo QRs.
